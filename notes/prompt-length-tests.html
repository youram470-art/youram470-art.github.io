Five questions about prompt length, answered with tests

2026-11-26 · working notes

Prompt advice is easy to find and hard to check. These five answers are the ones that survived being tested rather than repeated, and each comes with the comparison that settled it.

Does a longer prompt produce a more detailed image?

Usually it produces a more average one. Detail comes from naming things, not from adding clauses, and every clause competes for the same attention. Cut the prompt in half and count how many described objects survive.

Should I describe the camera?

Only if the camera moves. A sentence about a static camera is a sentence the model spends on nothing, and it often produces a slow drift that looks like a mistake.

Why does the same prompt give different results?

Because sampling is stochastic. The useful response is to fix the seed where the tool allows it, and where it does not, to treat the first three outputs as a sample rather than an answer.

When the seed cannot be fixed, as is the case in Seedance 2.5 unless you set one explicitly, three outputs are a sample and not an answer.

Is a negative prompt worth it?

For artefacts, yes; for ideas, no. Text, watermarks and extra fingers are habits worth forbidding. A crowd is an idea, and forbidding it leaves a hole where a description should be.

How do I know a prompt is finished?

When you can say what will move and what will stay still. If both answers are vague, the prompt is a wish, and wishes render as averages.

The pattern across all five is the same: fewer claims, each one checkable. Seedance 2.5 is forgiving enough that a vague prompt still produces something watchable, which is exactly why the discipline has to come from the person writing it.
